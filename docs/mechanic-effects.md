# 机匠三转技能特效

`src/DB/Skills/MechanicEffects.js` 集中声明机匠技能的渲染资源、播放阶段和持续状态。`SkillEffect.js` 与 `EffectTable.js` 分别接入技能和渲染配置，沿用公共特效开关、资源缓存及实体清理。

## 资源与表现

- 加农炮、火神炮、回旋斧、战斧飓风、挥斧重击等使用运行资源中已有的原生 STR；嵌套 STR 的贴图按自身目录解析。
- 火焰、冰冻投射、火箭拳、蒸汽、扫描与力场等缺少独立可直接播放的 STR，使用现有 kRO 贴图组合粒子表现。这些是 Web 客户端的实现，不声称与原生客户端的程序化特效逐帧一致。
- 未修改官方源材料或运行资源。新增引用应先核验 STR 格式、全部贴图及音效是否可从 Gateway 读取，不能仅按文件名猜测存在。

## 播放时机

- 命中特效使用伤害封包的目标和时间；火焰、冰冻、拳头投射物使用 `matchTravelDuration` 跟随伤害延迟。
- 战斧飓风、自毁使用成功施放封包在施法者位置播放，避免对每个受击目标重复生成施法者动画。
- 红外扫描、磁场使用服务端发送的技能伤害通知（包括无伤害通知）；修理、推进等使用成功通知。
- 中性屏障、隐形力场由服务端的 master 状态驱动，重复状态更新先清理再创建，关闭时移除；不靠固定计时器推测技能是否仍有效。

本轮完成配置、资源依赖与构建校验，实际动画位置、比例、移动状态和观感由游戏内人工验收；不等同于所有技能已完成真机验收。

## 固定地面特效

岩浆喷发由 `UNT_MAGMA_ERUPTION` 地面单位持有动画，坐标、出现和移除时间由服务端决定；伤害封包不再重复生成喷发动画。循环的画面与单次音效分离。

公共特效层收到施放地点时，仅对该实例取消实体跟随，不修改共享特效定义。光耀之堂、暴风雪、雷鸣风暴、圣灵降临、锤击及生命体毒雾／熔岩滑动／火山灰的区域表现使用地面施放阶段，避免在每次受击时重复生成完整区域；命中火花与主动跟随角色的状态效果保留原语义。
