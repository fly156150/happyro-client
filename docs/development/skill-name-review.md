# 技能与状态名称修改清单

此清单列出本次修改及参考依据，不将地区译名差异一概判为错误。

## 范围与依据

- 扫描当前生成表全部 1,767 条技能记录；核对 RO321 的 88 个职业页面，并补查 198 个独立技能页面（部分返回 404）。共匹配 1,125 条技能 ID 与 Aegis 标识。技能树共 1,138 个唯一技能，其中 102 个未获得本站对应资料，保留现有名称并标记待外部复核；另有 NPC、内部效果等非职业技能。派生攻击 5030 随主技能同步，不计入独立资料覆盖。不能将此次全量扫描等同于全部名称均已获得外部权威确认。
- 本次调整 126 个技能名，另同步 1 个派生攻击名称（共 127 个）。其余参考站差异保留项目现有合理译名，不整表照搬。技能效果和数值未改。
- 201 个已复核的技能效果标题直接读取技能名称，其中 95 个标题发生变化；保留颜色、倒计时与说明正文。
- `钢铁之心`（技能）／`霸体`（状态）保留：前者是技能名称，后者也是可独立理解的效果称呼，不视为错误。
- 灼伤、冻结、魔力中毒、卸除装备、四方加护等独立状态或共用图标不强行改成施加技能名。
- 旧版 `new_1-1` 至 `new_5-4` 的 20 张地图统一为“初心者修炼场”；船舶、岛屿、学院不受影响。
