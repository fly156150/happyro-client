# 保持登录与连接恢复

## 玩家行为

手机、平板与桌面共用以下规则，HTTP 和 HTTPS 均支持：

- 登录框“保持登录”默认不勾选，旧“记住账号”设置不视为长期登录授权；用户名继续记忆，密码不保存。
- 勾选后会话最长有效 30 天。关闭页面或浏览器后重新打开，认证成功直接进入选角；不会自动选中角色。
- 不勾选时凭据仅在当前页面内存中保存；页面内意外断线仍可免密恢复，刷新或关闭页面后需要重新登录。
- 游戏中断线时，回到前台自动认证并进入原角色。等待角色列表和 PIN 检查，以角色 ID 匹配，账号或服务器变化不自动进入旧角色。
- 原连接仍有效时只进行心跳检查，不重新登录；12 秒无响应才进入恢复。旧连接尚未退出时最多追加三次间隔 1.5 秒的认证，不踢掉另一处在线角色，不无限重试。
- 返回选角保留登录；登录页退出、选角返回、游戏退出与恢复窗口“退出登录”撤销当前会话。服务端强制下线取消自动恢复。
- 修改密码、账号状态或有效期、封禁与会话过期使凭据失效。服务器重启后有效的持久会话继续可用。

地图和位置、血量、物品等以服务端重新下发状态为准。同地图恢复镜头距离与角度；换地图使用正常镜头。不恢复 NPC 对话或交易窗口，不重放购买、技能等操作。进入后台沿用现有停止自动战斗等生命周期处理。

## 凭据与协议

GameSession.js 通过同源 /api/game-session/create、resume、revoke 与 Gateway 交互。正常密码认证成功后，使用服务端 WebToken 证明身份来创建会话；没有将 WebToken 直接当作游戏登录密码。

Gateway 使用系统随机源生成 256 位凭据。持久凭据放入 HttpOnly、SameSite=Strict Cookie，HTTPS 另设 Secure；HTTP 使用独立 Cookie 名称，不设置 Secure。Cookie 限定 /api/game-session 路径。HTTP 与 HTTPS、不同主机入口需要分别首次登录。

页面内会话不写 Cookie、localStorage 或 sessionStorage。恢复接口轮换凭据并生成有效期 30 秒的一次性票据，登录服务原子消费后继续执行原有账号、客户端校验和选角/PIN 流程。数据库仅保存凭据与票据摘要，不新增明文密码存储。

HappyRO 扩展登录包 0x0d05 长度 91 字节：包号 uint16、用户名 24 字节、十六进制票据 64 字节、clienttype uint8。PACKETVER 保持 20211103，需要配套更新客户端、Gateway、login-server、web-server 及会话数据库结构。

HTTP 会话按产品要求开放，传输层不具备 HTTPS 的保护。API 拒绝跨站来源，响应禁止缓存，凭据不写诊断日志。会话创建或恢复失败回到普通登录；主动退出撤销失败会明确提示，不能报告已退出。

## 实现与部署

- Engine/Auth/GameSession.js：串行化创建、恢复、撤销请求，页面内凭据。
- Engine/Recovery/RecoveryController.js：恢复意图、身份匹配、PIN 等待和超时。
- Engine/Recovery/GameRecovery.js：前后台生命周期、共享弹窗和镜头恢复。
- LoginEngine、CharEngine、MapEngine：认证、选角、地图接入，清理旧交互。
- NetworkManager：心跳与连接代次，拒绝迟到连接覆盖当前连接。

服务端先执行 sql-files/upgrades/upgrade_20261012_sessions.sql，再更新运行服务。该文件建立会话表和密码／封禁变更撤销触发器；根仓库新数据库初始化与部署工具均接入此步骤，保留旧数据库升级时也会执行，失败阻止游戏服务启动。

## 验证边界

146 项客户端恢复、网络、登录 UI、自动战斗、镜头、NPC、交易与商店相关回归通过；10 项 Gateway／代理测试验证 HTTP/HTTPS Cookie、页面会话、轮换、撤销及跨站拒绝。实际 Gateway、Web、Login 与 MariaDB 联调验证票据只用一次、旧凭据失效、退出、密码修改后改回、封禁后解封及过期。

Chromium 三类视口实际登录、断开游戏连接、自动回原角色、重新打开页面进入选角及主动退出通过；另验证 HTTPS Secure Cookie、未勾选时的页面内恢复及完全关闭 Chromium 后重启免密选角。PWA 使用 --all 完整构建，Gateway 已核验产物 mv5079gg。

iOS/Android 真机后台冻结与页面被系统回收仍待验收。页面被回收按重新打开处理：持久登录进入选角，页面会话要求重新登录；不声称跨页面保留原游戏画面。
